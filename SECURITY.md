# Security

## Reporting a problem

If you find a security problem in Range Book, please email **hello@rangebook.org** with "Security" in the subject, instead of opening a public GitHub issue. A public issue would show everyone how to use the problem before there's a fix.

Please include:

- what the problem is and what someone could do with it;
- how to reproduce it (the steps, a request, or a short script);
- the Range Book version (bottom of the More menu, or the top of `public/changelog.json`).

You'll get a reply as soon as possible. Range Book is a one-person project, so a fix may take a few days. Once it's fixed and released, you'll be thanked in the release notes if you'd like.

## Supported versions

Only the newest release (the `main` branch and the latest Docker image) gets security fixes. If you run your own Range Book, update to the newest version.

## Please don't

- test against someone else's Range Book server without their permission;
- try to read, change or delete other people's data;
- send reports by public comment or issue.
